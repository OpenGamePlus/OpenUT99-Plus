**Unreal Tournament на новом движке.** OpenUT99-Plus — независимая реимплементация Unreal Engine 1, движка Unreal Tournament (1999), написанная с нуля. Она читает файлы самой игры из вашей установки и запускает их на современных системах, включая код игры на UnrealScript. Долгосрочная цель — играть вместе с оригинальной игрой и против неё: оригинальные клиенты на нашем сервере, наш клиент на оригинальных серверах.

## Что работает сегодня

- **Каждый объект установки декодируется побайтово**: все 396 пакетов с картами, текстурами, звуками, музыкой, шрифтами, мешами, анимациями и байткодом UnrealScript читаются инструментами на Python и сверяются с движком на C++.
- **Все 83 карты загружаются и отрисовываются**: текстурированный BSP, запечённые карты освещения, небо, декорации, подбираемые предметы и анимированные персонажи.
- **Работает собственный UnrealScript игры**: наша виртуальная машина выполняет все 1 604 класса игры. Она запускает Deathmatch на каждой карте без единой ошибки скрипта. Боты ходят по сети путей, открывают двери, ездят на лифтах, подбирают оружие и предметы, сражаются, погибают, набирают очки и возрождаются.
- **Физика, измеренная на оригинале**: наши собственные скрипты-зонды работают на оригинальном выделенном сервере и точно записывают, как движутся пешки ([ADR 0008](docs/architecture/adr/0008-probe-the-original.md)). Ступени, проходимые склоны, скольжение по крутым склонам, граница стены и прыжок на уступ совпадают с оригиналом; начало скольжения пока нет.

> [!NOTE]
> **Стадия исследования.** Можно сыграть Deathmatch против ботов, летать по любой карте или смотреть, как играют боты. Пока нет звука, HUD, оружия в руках, меню и сети, а значительная часть физики и ИИ ещё временная ([известный долг](docs/roadmap/debt.md)).

> [!IMPORTANT]
> **Игровой контент не включён — используйте свои данные.** В этом репозитории только исходный код: никаких пакетов, карт, текстур, звуков, музыки или исполняемых файлов. Движок читает их из копии Unreal Tournament, которой **вы законно владеете**, здесь она называется `<UT99_DIR>`. Проверено с версией из Steam и патчем 469f от [OldUnreal](https://www.oldunreal.com/).

## Как попробовать

Готовых сборок пока нет. Соберите движок (см. [Сборка](#сборка)) и укажите ему папку Unreal Tournament, ту, где лежат `Maps/` и `System/`:

```sh
build/ut_mapview "<UT99_DIR>" DM-Deck16][                    # полёт по карте
build/ut_mapview "<UT99_DIR>" DM-Morpheus --play --follow    # смотреть, как играют боты, следуя за одним
build/ut_mapview "<UT99_DIR>" DM-Deck16][ --player --mouse-free   # сыграть Deathmatch против ботов
build/ut_script "<UT99_DIR>" --map DM-Codex 60               # без окна: минута матча, вывод в консоль
```

| Управление | |
|---|---|
| Обзор | удерживать кнопку мыши и тянуть, или стрелки |
| Полёт | WASD, shift быстрее |
| Игра (`--player`) | WASD — движение, мышь — обзор, левая / правая кнопка — огонь / альтернативный огонь, пробел — прыжок, Ctrl — присесть, 1-0 — оружие |
| Просмотр матча | F — следовать за следующим ботом; Esc — выход |

## План развития

Порядок и критерии завершения — в [docs/roadmap/roadmap.md](docs/roadmap/roadmap.md):

1. **Пакеты и объекты** (готово): каждый объект каждого пакета прочитан без остатка байтов.
2. **Просмотрщик уровней** (готово): каждая карта игры в движке на C++.
3. **Игровой процесс** (в работе): акторы, физика, оружие, боты и режимы игры, вплоть до Deathmatch против ботов.
4. **Точность**: сравнение бок о бок с оригиналом.
5. **Сеть**: оригинальный клиент подключается к нашему серверу, а наш клиент — к оригинальному серверу.

## Сборка

C++17, CMake, SDL2 и OpenGL 3.3 (libepoxy). В Debian или Ubuntu:

```sh
sudo apt install cmake g++ git pkg-config libsdl2-dev libepoxy-dev
cmake -S . -B build && cmake --build build -j
ctest --test-dir build
# -> build/ut_mapview (окно), build/ut_script (без окна), build/ut_dump (инспектор пакетов)
```

## Прозрачность

- **Кто поддерживает:** OpenGamePlus. Я люблю старые игры и хочу и дальше играть в Unreal Tournament с друзьями на современных системах, с открытым движком, который сообщество сможет поддерживать.
- **Как ведётся работа:** я работаю с [Claude Code](https://claude.com/claude-code), ассистентом программирования от Anthropic. Код и документация, включая этот README и его переводы, пишутся с его помощью. Коммиты, сделанные так, содержат строку `Co-Authored-By: Claude` в сообщении, поэтому их можно найти в истории с помощью `git log`.
- **Оригинальный код:** код оригинального движка не копируется в этот репозиторий, а его нативные бинарные файлы не дизассемблируются. Движок пишется на основе файлов данных игры, собственного UnrealScript игры (читается, чтобы понять поведение, но никогда не копируется), наблюдения за работой оригинальной игры и публичной документации ([ADR 0004](docs/architecture/adr/0004-clean-room-sources.md)).
- **Чем это не является:** это не официальный проект, и он не связан с Epic Games. Он не содержит файлов игры.
