# Glossary

| Term | Meaning |
|---|---|
| UE1 | Unreal Engine 1, the engine of Unreal (1998) and Unreal Tournament (1999) |
| package | container file holding named objects (`.u .unr .utx .uax .umx .uxx`); see [formats/package.md](formats/package.md) |
| export / import | object defined in this package / object referenced from another package |
| compact index | variable-length signed integer used throughout packages |
| generation | per-save record (export count, name count) in the package header |
| UnrealScript | the game's scripting language; compiled to bytecode inside `.u` packages, source text kept alongside |
| replication | UE1 networking: actor properties and function calls sent per `replication` block |
| BSP | binary space partition: level geometry (`Model`) used for rendering and collision |
| 436 / 469 | final Epic patch (436) and the community OldUnreal patch series (469a–469e) |
| `<UT99_DIR>` | placeholder for the retail install path |
